About america.sx

On-chain launch & supply-distribution forensics for Solana

america.sx takes a Solana token mint address and examines how its supply was acquired. It runs fifteen independent on-chain signals — wallet ages, funding sources, entry timing, balance patterns, transaction-fee fingerprints, liquidity depth and more — then checks how many of them point the same way. One signal never decides on its own.

The verdict

Bundledsupply distribution looks manufactured — several hard signals agree and coordinated buying is visible.
Cabaleddistribution is insider-heavy or unusual, but without the hard signatures of a bundle.
Organicno coordinated distribution pattern found. This does not mean "safe" or "will go up".
Inconclusivetoo little on-chain data was retrievable for a call — usually a very active or old token where wallet histories exceed the query budget.

Launch analysis

The core of the engine. Using the pump.fun bonding-curve address (or the DEX pair) as an anchor, we page the token's signatures back to block one and parse the first ~40 transactions to reconstruct the actual launch buyers. The bundle signals run on those wallets — not on today's whales. When the launch history is too long to reach within budget, the engine falls back to current holders and says so.

The fifteen signals

    Two numbers

    Every scan returns a score (how well the token fits its category — not a price prediction) and a confidence (how much data was available for the call).

    Limits

    Results are an algorithmic opinion, not a factual finding. They can produce false positives and false negatives, and the verdict changes as on-chain data changes. Not investment advice.

    Data & cost

    One scan is roughly 125 RPC calls against Solana infrastructure, plus DexScreener for market data. Results are cached for 15 minutes so popular tokens are not re-scanned on every request.

    These results are an algorithmic opinion, not a factual finding.

    Each classification is the current output of heuristic rules applied to public on-chain data. It describes a pattern; it carries no claim of intent, fraud or crime. It can produce false positives and false negatives. "Organic" means "no manipulation pattern found" — not "safe" or "will go up". As data changes, the verdict for the same token changes too. Not investment advice.
